this repository contains my internship project on image processing, data augmentation and machine learning using python. The project involved image preprocessing with opencv, dataset handling with Pytorch, and K-means clustering on the MNIST handwritten digit dataset

Project Task:
Image loading, Data augmentation using resizing, random horizontal flipping, and tensor conversion.
Dataset management using ImageFolder and DataLoader.
K-Means clustering on the MNIST dataset.
Performance evaluation using the Macro F1-Score.

Results:
Successfully performed image preprocessing and augmentation.
Implemented K-Means clustering with 10 clusters.
Achieved a Macro F1-Score of approximately **0.776**.
